Vine Turtle Nest (VineTurtle Studio) wants you to feel at ease while browsing this site and using our desktop apps. This policy explains what information we do and do not process, and how you can reach us.

The short version: This site is pure-static by default — no accounts, no analytics or ad scripts; only when you use the optional comment or like features does any necessary data exchange with GitHub or Cloudflare happen. Desktop apps read and write only your own files locally and never upload anything.

1. Scope

This policy covers:

  • Vine Turtle Nest (grapeleafi.top) and its blog, project and gallery pages;
  • our released or planned desktop apps, such as VinePalma Player, VinePalmaFlow, VinePalmaToolbox, VinePalmaUninstaller and more.

Sites and desktop apps handle data differently; each is described below.

2. What this site collects

  • No registration requiredThe site is pure-static pages: reading posts, projects and the gallery needs no account and collects no personal information.
  • No analytics or adsPages embed no third-party analytics, no pixel tracking, and no profiling.
  • Self-hosted assetsStyles, scripts and images all come from this site. Only when you use the comment feature does the page load GitHub's giscus component.

Hosting logs: This site is hosted on GitHub Pages. As the hosting provider, GitHub may record access logs (IP address, browser identifier, access time) for security and traffic statistics. Those logs are handled under GitHub’s own policies; we only see aggregated visit data and cannot identify individuals from it.GitHub Privacy Statement

3. Comments, likes & view counts (optional)

The site loads no interactive components by default. Data is processed only when the following features are enabled:

  • Commentsgiscus is used; comment content lives in this project’s GitHub Discussions. Posting requires signing in to a GitHub account, and GitHub handles account data under its own privacy statement; comments are moderated by us and can be removed when necessary.
  • Likes & view countsCloudflare Workers + D1 record content identifiers and counts. To prevent abuse, the server briefly processes a hash of the IP address — raw IPs are never stored, and nothing is linked to accounts.
  • Local dedupthe browser's localStorage records marks like “read today” and “already liked”, solely to avoid duplicate counting; you can clear them anytime from your browser settings.

Third-party services: Comments connect to GitHub (giscus); likes/view counts connect to Cloudflare. Each processes necessary network and account data under its own privacy policy. We never sell interaction data or use it for ad profiling.

4. Cookies & local storage

  • The site itself writes no cookies. Once giscus comments are enabled, the comment component runs inside GitHub's iframe and may use cookies or local storage under GitHub's policies; we cannot read anything inside it.
  • Likes/view counts use localStorage to record dedup marks — no personal identity information involved.
  • The site's content admin backend runs only on your own computer (a local service, never exposed to the internet), using the browser’s localStorage / sessionStorage to stash edit drafts and this session’s temporary token. That data stays in your browser and is sent to no server.
  • After a page refresh or browser close, the session token expires; drafts can be cleared manually from the admin panel.

5. External links

The site may contain links to GitHub, software download pages and other third-party sites. Clicking through takes you off this site; those sites process information under their own privacy policies — we cannot control them and are not responsible for their content. Please read their privacy statements before submitting any information.

6. Desktop apps (VinePalma Player etc.)

  • Local file accessTo play or process the files you choose, apps request read access to local storage. The permission applies only to files you actively select — no scanning of unrelated directories.
  • No personal data collectionApps never collect, store or transmit personal identity information — no names, emails, phone numbers or device identifiers, by any means.
  • No network uploadsPlayer apps never upload audio, playlists or usage records to servers; local-first apps (like VinePalmaFlow) keep data on your device by default.
  • Data stays localPlaylists, preferences and other data you create are stored only on your machine and removed when you uninstall.
  • No third-party SDKsApps contain no third-party analytics, advertising or social platform SDKs.

7. Children's privacy

Neither this site nor our apps knowingly collect personal information from users of any age, and the content contains no adult themes — suitable for browsing and use at any age. If you believe we hold a minor's information by accident, email us via the address below and we'll delete it promptly.

8. Your rights & contact

The site itself collects no personally identifiable information. If you have used the comment feature, comment content lives in GitHub Discussions and can be edited or deleted on GitHub; likes/view counts store only numbers and cannot be linked to any individual.
