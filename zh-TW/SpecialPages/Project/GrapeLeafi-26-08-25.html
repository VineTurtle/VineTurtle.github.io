GrapeLeafi 葡葉醬的溫暖小窩

🚧 迭代中📅 2024
#網頁開發#靜態網站#社區站點

GrapeLeafi 是 VineTurtleStudio 維護時間最長的專案——一個面向 Key 社遊戲愛好者社群的純靜態粉絲站點「葡葉醬的溫暖小窩」。它沒有框架、沒有構建工具、沒有後端，全部程式碼就是幾個 HTML、CSS 和 JS 檔案，直接部署在 GitHub Pages 上。正因為"誰都能改"，它在幾年間經歷了多次手工迭代，也積累了大量靜態網站的典型經驗教訓。

站點概覽

網站圍繞虛擬角色「葡葉醬」（GrapeLeafi）與「葡家」角色群設定展開，主色調是暖橙與奶黃，全站使用 Summer Pockets 主題的自定義滑鼠指標，左下角常駐 Live2D 看板娘。頁面結構非常剋制：橙色固定頁頭 + 圓角卡片式內容區 + 淺橙頁尾，移動端收進右上角漢堡抽屜選單。四個頁面（首頁 / 葡家介紹 / 關於我們 / 聯絡我們）共享同一套樣式表，每個頁面的 favicon 還各用了一枚不同的「糰子」圖示，是早期複製頁面時留下的小趣味。

核心功能實現

建群週年倒計時：JS/Countdown.js 只有 29 行，目標日期錨定在每年的 12 月 6 日——如果今年的日期已過，自動把年份推到下一年，於是"三週年"的橫幅其實每年都會自動續期，永不過期。

角色生日提醒：JS/birthday.js 內建了約 140 條 Key 社角色生日資料（月-日格式），每次載入時換算成"未來 30 天內"的視窗，按剩餘天數排序渲染成卡片列表；30 天內沒人過生日時顯示一句"放鬆一下吧～"。

QQ 群二維碼彈窗：純 CSS 的 :hover 方案——滑鼠懸停「加入QQ群」膠囊按鈕時，下方彈出白色圓角卡片展示群二維碼，零 JS 參與。

Live2D 看板娘：直接引用 jsDelivr 上的 stevenjoezhang/live2d-widget，一行 script 引入即插即用。

為什麼堅持純靜態

社群站點的訪問者不需要登入、發帖這類動態能力，而維護者（也就是我們）更希望"用記事本也能改"。純靜態意味著：沒有伺服器費用、沒有資料庫備份、沒有安全補丁要打，GitHub Pages 推送即上線。代價是所有"動態感"都必須在前端模擬——倒計時、生日提醒、二維碼彈窗，全部是瀏覽器本地計算的產物。

維護中遇到的坑

這個專案幾乎是靜態站踩坑教科書：生日提醒的"今天過生日"分支因為日期比較方式問題從未觸發過（後來我們把它寫進了部落格《純靜態網站的四個經典坑》）；QQ 群二維碼在手機上因為沒有 hover 永遠彈不出來；資原始檔名裡混著中文、空格和括號，GitHub Pages 的 Linux 伺服器大小寫敏感，一次改名就批次 404；Live2D 引用 @latest 版本號，上游一更新全站看板娘跟著"抽獎"。這些坑的完整復盤見部落格文章，這裡先按下不表。

與主站的關係

GrapeLeafi 的頁頭導航裡掛著「憨龜總站」——也就是你現在看到的藤棲龜舍。它像是工作室的"對外會客廳"：技術更樸素、語氣更日常，負責把社群氛圍撐起來；而藤棲龜舍則承載正式的專案與部落格。兩個站點共用同一批角色設定與插畫資源，畫廊裡的許多作品最早就是為葡家創作的。

2026 年 11 月：搬進子域名，重新裝修

這一版做了一次徹底的整理：小窩遷到獨立子域名 leafi.grapeleafi.top，與藤棲龜舍各自獨立部署；頁面結構與樣式全部重寫，頁頭改為單行導航 + 移動抽屜，圖片壓縮成體積更小的 JPEG，首屏輕了不少。

當年那些"坑"也順手填平了：生日資料從 JS 裡搬到 data/birthdays.json，週年倒計時改由 data/countdown.json 驅動並自動計算"第幾週年"；QQ 群二維碼改成點選展開，鍵盤和手機上都能用；Live2D 固定到 0.9.2 並在桌面端空閒時才載入，不再跟著上游"抽獎"。同時補上了 sitemap、robots、404 與分享卡片。

結語

如果你也想做一個屬於自己的粉絲站，GrapeLeafi 的倉庫結構也許是最友好的起點：沒有依賴、沒有構建，clone 下來雙擊 index.html 就能跑。剩下的，就是慢慢把內容種進去，等它自己生長。
