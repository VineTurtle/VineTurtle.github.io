藤棲龜舍（VineTurtle Studio）希望你在瀏覽本站、使用我們的桌面應用時都能放心。這份策略說明我們處理哪些資訊、不處理哪些資訊，以及你可以怎麼聯繫我們。

一句話版本：本站預設是純靜態站點，不設帳號、不接統計與廣告腳本；只有在你使用可選的評論或點讚功能時，才會與 GitHub 或 Cloudflare 發生必要的資料互動。桌面應用只在本機讀寫你自己的檔案，不做任何上傳。

1. 適用範圍

本策略適用於：

  • 藤棲龜舍官網（grapeleafi.top）及其下的部落格、專案、畫廊等內容頁面；
  • 我們發布或計劃發布的桌面應用，例如 VinePalma Player、VinePalmaFlow、VinePalmaToolbox、VinePalmaUninstaller 等。

站點與桌面應用的資料處理方式不同，下文分別說明。

2. 本站點收集哪些資訊

  • 預設不需要註冊本站主體是純靜態頁面，瀏覽文章、專案和畫廊不需要帳號，也不要求提交個人資訊。
  • 不使用統計腳本和廣告頁面不植入第三方分析工具，不使用像素追蹤，也不做使用者畫像。
  • 主體資源自託管樣式、腳本、圖片都來自本站。只有在你使用評論功能時，頁面才會載入 GitHub 提供的 giscus 評論元件。

託管方日誌：本站託管在 GitHub Pages。作為託管服務商，GitHub 可能記錄存取日誌（如 IP 位址、瀏覽器標識、存取時間）用於安全防護和流量統計。這些日誌由 GitHub 按自身政策處理，我們只能看到聚合後的存取資料，無法據此識別具體個人。GitHub 隱私權聲明

3. 評論、點讚與閱讀量（可選）

本站預設不載入任何互動元件。只有在站點啟用以下功能時，相關資料才會被處理：

  • 評論使用 giscus，評論內容存放在本專案的 GitHub Discussions 中。發表評論需要登入 GitHub 帳號，GitHub 會按其隱私聲明處理帳號資訊；評論由我們審核，必要時可刪除。
  • 點讚與閱讀量使用 Cloudflare Workers + D1 記錄內容標識和計數。為防止刷量，伺服器會短暫處理 IP 位址的雜湊值，不保存原始 IP，也不與帳號關聯。
  • 本地去重瀏覽器 localStorage 會記錄「今天已閱讀」「已點讚」等標記，僅用於避免重複計數；你可以隨時在瀏覽器設定中清除。

第三方服務：啟用評論時會連接 GitHub（giscus）；啟用點讚/閱讀量時會連接 Cloudflare。它們分別按各自的隱私政策處理必要的網路與帳號資訊。我們不會把互動資料出售或用於廣告畫像。

4. Cookie 與本地儲存

  • 本站主體不寫入 Cookie。啟用 giscus 評論後，評論元件運行在 GitHub 的 iframe 中，可能按 GitHub 的政策使用 Cookie 或本地儲存，我們無法讀取其中的內容。
  • 點讚/閱讀量功能使用 localStorage 記錄去重標記，不包含個人身份資訊。
  • 本站的內容管理後台只在你自己的電腦上執行（本地服務，不對公開網路開放），使用瀏覽器 localStorage / sessionStorage 暫存編輯草稿和本次工作階段的臨時權杖。這些資料留在你的瀏覽器裡，不發送到任何伺服器。
  • 頁面重新整理或關閉瀏覽器後，工作階段權杖即失效；草稿可由你在後台手動清除。

5. 外部連結

站內可能出現指向 GitHub、軟體下載頁等第三方站點的連結。點擊後你即離開本站，第三方站點會按其自己的隱私政策處理資訊，我們無法控制，也不對其內容負責。建議你在提交任何資訊前先閱讀對方的隱私說明。

6. 桌面應用（VinePalma Player 等）

  • 本機檔案存取為了播放或處理你選擇的檔案，應用會請求讀取本機儲存的權限。該權限僅用於你主動選擇的檔案，不會掃描無關目錄。
  • 不收集個人資訊應用不會以任何方式收集、儲存或傳輸姓名、信箱、電話、裝置標識等個人身份資訊。
  • 不做網路上傳播放器類應用不把音訊、播放清單或使用記錄上傳到伺服器；本地優先類應用（如 VinePalmaFlow）的資料預設只保存在你的裝置上。
  • 資料留在本地播放清單、偏好設定等由你建立的資料僅保存在本機，解除安裝應用後隨之清除。
  • 不整合第三方 SDK應用不包含第三方分析、廣告或社群平台 SDK。

7. 兒童隱私

本站與我們的應用不會有意收集任何年齡層使用者的個人資訊，內容也不包含成人主題，適合各年齡層瀏覽與使用。若你認為我們無意中持有了未成年人的資訊，請透過下方信箱聯繫我們，我們會盡快刪除。

8. 你的權利與聯繫方式

本站主體不收集可識別個人身份的資訊。如果你使用過評論功能，評論內容保存在 GitHub Discussions，可在 GitHub 上編輯或刪除；點讚/閱讀量只保存計數，無法關聯到具體個人。如果你對隱私處理有疑問，可以隨時透過信箱聯繫：

我們可能會更新本策略，例如新增統計工具或上線新的應用功能時。任何實質性變更都會更新本頁頂部的「最後更新」日期；如變更影響較大，我們會在站內顯著位置提示。建議你定期回來查看。
