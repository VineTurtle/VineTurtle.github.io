藤棲亀舎（VineTurtle Studio）は、本サイトの閲覧やデスクトップアプリのご利用を安心していただけるようにしたいと考えています。このポリシーでは、私たちが処理する情報と処理しない情報、そしてお問い合わせの方法を説明します。

ひとことで言うと：本サイトは既定で純静態サイトであり、アカウントも統計・広告スクリプトもありません。オプションのコメント機能やいいね機能を使うときにだけ、GitHub または Cloudflare との必要なデータのやり取りが発生します。デスクトップアプリはあなた自身のファイルをローカルで読み書きするだけで、一切アップロードしません。

1. 適用範囲

このポリシーの適用対象：

  • 藤棲亀舎公式サイト（grapeleafi.top）とその配下のブログ・プロジェクト・ギャラリーなどのコンテンツページ。
  • 私たちが公開または公開を計画している デスクトップアプリ。たとえば VinePalma Player、VinePalmaFlow、VinePalmaToolbox、VinePalmaUninstaller など。

サイトとデスクトップアプリではデータの取り扱いが異なるため、以下でそれぞれ説明します。

2. 本サイトが収集する情報

  • 登録は既定で不要本サイトの本体は純静態ページで、記事・プロジェクト・ギャラリーの閲覧にアカウントは不要であり、個人情報の提出も求めません。
  • 統計スクリプトと広告は不使用ページにサードパーティの分析ツールを埋め込まず、ピクセル追跡もユーザープロファイリングも行いません。
  • 主要リソースはセルフホストスタイル・スクリプト・画像はすべて本サイトから提供します。コメント機能を使うときにのみ、GitHub 提供の giscus コメントコンポーネントを読み込みます。

ホスティング側のログ：本サイトは GitHub Pages でホストされています。ホスティング事業者として、GitHub はアクセスログ（IP アドレス、ブラウザ識別子、アクセス時刻など）をセキュリティ保護やトラフィック統計のために記録する場合があります。これらのログは GitHub 自身のポリシーで処理され、私たちに見えるのは集計後のアクセスデータのみで、特定の個人を識別することはできません。GitHub プライバシー声明

3. コメント・いいね・閲覧数（オプション）

本サイトは既定でインタラクティブなコンポーネントを一切読み込みません。以下の機能が有効になったときにのみ、関連データが処理されます：

  • コメントgiscus を使用し、コメント内容は本プロジェクトの GitHub Discussions に保存されます。コメントの投稿には GitHub アカウントへのログインが必要で、GitHub がそのプライバシー声明に従ってアカウント情報を処理します。コメントは私たちが審査し、必要に応じて削除できます。
  • いいねと閲覧数Cloudflare Workers + D1 でコンテンツ識別子とカウントを記録します。不正な水増しを防ぐため、サーバーは IP アドレスのハッシュ値を短時間だけ処理し、元の IP は保存せず、アカウントとも紐付けません。
  • ローカル重複排除ブラウザの localStorage には「今日既読」「いいね済み」などのマークが記録され、重複カウントの回避だけに使われます。いつでもブラウザの設定から消去できます。

サードパーティサービス：コメント有効時は GitHub（giscus）に、いいね/閲覧数有効時は Cloudflare に接続します。それぞれが自社のプライバシーポリシーに従って必要なネットワーク・アカウント情報を処理します。私たちがインタラクションデータを販売したり広告プロファイリングに使ったりすることはありません。

4. Cookie とローカルストレージ

  • 本サイトの本体は Cookie を書き込みません。giscus コメントを有効にすると、コメントコンポーネントは GitHub の iframe 内で動作し、GitHub のポリシーに従って Cookie やローカルストレージを使う場合があります。その内容を私たちが読むことはできません。
  • いいね/閲覧数機能は localStorage で重複排除マークを記録します。個人を識別する情報は含まれません。
  • 本サイトの コンテンツ管理バックエンド はあなた自身の PC でのみ動作し（ローカルサービス、公開ネットワークには非公開）、ブラウザの localStorage / sessionStorage を使って編集下書きと今回のセッションの一時トークンを退避します。これらのデータはブラウザの中にとどまり、どのサーバーにも送信されません。
  • ページ再読み込みやブラウザ終了後、セッショントークンは失効します。下書きは管理画面から手動で消去できます。

5. 外部リンク

サイト内には GitHub やソフトのダウンロードページなど、サードパーティサイトへのリンクが現れることがあります。クリックした時点で本サイトを離れ、そのサイトは独自のプライバシーポリシーで情報を処理します。私たちには制御できず、その内容にも責任を負いません。情報を送る前に、相手のプライバシー説明をお読みください。

6. デスクトップアプリ（VinePalma Player など）

  • ローカルファイルアクセス選択したファイルを再生・処理するため、アプリはローカルストレージの読み取り権限を要求します。この権限はあなたが能動的に選んだファイルだけに使われ、無関係なディレクトリを走査しません。
  • 個人情報を収集しないアプリは、氏名・メールアドレス・電話番号・デバイス識別子などの個人識別情報を、いかなる方法でも収集・保存・送信しません。
  • ネットワークへアップロードしないプレーヤー系アプリは音声・プレイリスト・利用記録をサーバーにアップロードしません。ローカルファースト系アプリ（VinePalmaFlow など）のデータは既定であなたのデバイス上にのみ保存されます。
  • データはローカルに滞在プレイリストや設定など、あなたが作ったデータは本機にのみ保存され、アプリをアンインストールすると一緒に消えます。
  • サードパーティ SDK を同梱しないアプリにはサードパーティの分析・広告・SNS プラットフォーム SDK は含まれません。

7. 児童のプライバシー

本サイトと私たちのアプリは、年齢を問わずユーザーの個人情報を意図的に収集することはなく、コンテンツにも成人向けテーマは含まれず、どの年齢層の方でも安心して閲覧・利用できます。万一未成年者の情報を意図せず保有していた場合は、下記のメールアドレスからご連絡ください。速やかに削除します。
