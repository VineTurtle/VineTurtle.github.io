VinePalmaToolbox：開発記録

🚧 継続開発中📅 2026
#Tauri#ソフトウェア開発#Linux

まっさらな Linux システムで、私たちはよくこうした困った場面に遭遇します：画像を 1 枚変換したいだけなのに、広告ポップアップが絶えないオンラインツールを開き、第三者サーバーへのファイルアップロードのプライバシーリスクまで心配しなければならない；テキストのハッシュを計算したいのに、システム標準の端末コマンドは一般ユーザーに優しくない。散在する細かなニーズのために、関連性のない十数本のソフトをインストールすることになりがちで、メモリ使用量は暴走し、体験は粉々です。

そこで私たち VineTurtle Studio 開発チームは、Tauri + React で開発するこの多機能デスクトップツールボックスを設計・開発しました。極めて低いリソース占有で、日常の開発・オフィスワークで高頻度に使う小ツールを一か所にまとめています。

プロジェクトの背景と目標

従来のデスクトップツール集は Electron のような重いフレームワークが多く、数百 MB のメモリを当然のように占領します。一方のオンライン Web ツールには「ネット接続が必須、プライバシーが不安、機能が点在」という構造的な弱点があります。軽くて美しく、入れてすぐ使えるローカルツールボックスを目指しました。Tauri 2 + Rust でネイティブバックエンドを組み、フロントは Web 技術——メモリ使用量は同種製品よりはるかに少なく、すべてのデータはローカルで処理され、ファイルは一切アップロードされません。プライバシーの安全を文字どおり実現しています。

技術アーキテクチャ

VinePalma Toolbox は Tauri 2 をアプリフレームワークとして採用し、フロントは React 19 + TypeScript + Vite、バックエンドは Rust がネイティブ能力を提供します。純フロントで足りる便利ツール（画像処理・エンコード変換・テキスト処理など）は WebView 内で完結し、大きなファイルやシステムファイルが絡む場面（ハッシュ計算・一括リネーム・重複ファイル探索・音声動画処理）は Rust コマンドで実装し、性能と安全の両立を図っています。

音声動画の能力はアプリに同梱した FFmpeg が提供します。インストーラーをできるだけ小さくするため、ビルドスクリプトは必要なコーデックだけを含む最小化静的版をソースからコンパイルし（1 個あたり約 7MB）、vp-ffmpeg / vp-ffprobe という名で Tauri の外部バイナリとして同梱配布します。実行時は内蔵バイナリを優先呼び出しし、システム標準の /usr/bin は決して汚しません——インストールした瞬間から使え、ffmpeg を手動設定する必要はありません。

機能の特徴

画像ツール：PNG / JPEG / WebP / BMP / TIFF / ICO / GIF / SVG など十数種の形式の相互変換に、一括変換と拡大縮小を対応。画像圧縮は目標サイズ・品質・辺長の 3 モードで体積を制御。画像はワンクリックで Base64 や Data URL に変換できます。さらに画像からのスポイト、縦/横/グリッド/スマートレイアウトでの画像連結、複数画像の PDF 合成も可能です。

テキストツール：テキストの重複排除はソートと大小文字無視に対応。文字数カウントは文字・漢字・単語・行数・段落・バイトまで細分。JSON の整形 / 圧縮 / 検証にワンクリックで YAML・TOML・CSV へ変換。大小文字変換は camelCase・snake_case・kebab-case・定数など 12 種の命名スタイルをカバー。テキスト比較は差分をハイライトし、追加・削除を集計します。

エンコード変換：Base64 のエンコード/デコードは中国語テキスト・URL セーフモード・ファイル全体のエンコードに対応。URL・HTML 実体・Unicode・JS/CSS 文字列のエスケープ/アンエスケープも一式そろう。進数変換は 2/8/10/16/32/36 進と補数に対応。QR コード生成は色・誤り訂正率・白枠をカスタムでき、PNG/SVG で書き出せるほか、画像から QR の内容を逆読みすることもできます。

開発者ツール：UUID ジェネレーターは v1 / v4 / v7 の 3 バージョンと一括生成に対応。タイムスタンプ変換は秒/ミリ秒・ISO・UTC・相対時間に対応。ランダムパスワード生成には強度判定が付属。色変換は HEX / RGB / HSL / CMYK をカバーし、パレットとコントラスト判定付き。ハッシュ計算は MD5 / SHA-1 / SHA-224 / SHA-256 / SHA-384 / SHA-512 でテキストもファイルも可。正規表現テスターはマッチをリアルタイムでハイライトし、置換結果をプレビュー。ほかに数式電卓と JWT デコード（HS256/384/512 の署名検証付き）。

ファイルツール：一括リネームは接頭辞・接尾辞・連番・検索置換・大小文字ルールに対応。重複ファイル探索はまずサイズでグループ化し、同サイズのファイルに対してストリーミングで MD5 を計算して確認——大きなディレクトリを走査しても固まりません。

音声動画ツール：動画から音声抽出、音声形式の相互変換（MP3 / WAV / FLAC / M4A / OGG など）、動画の指定時刻でのフレーム切り出しや動的 GIF への変換、音声のカット編集（フェードイン/アウト対応）と複数音声の結合——すべて内蔵 ffmpeg が駆動し、リアルタイム進捗といつでもキャンセルできる完全なタスク機構を備えています。

その他のツール：単位換算、日付計算、乱数生成、数値の漢数字（大字）変換など、日常的な小機能。

体験の細部：ホームのカードは 7 つのカテゴリに分けて表示し、キーワードの全体検索・お気に入り・最近の使用に対応。各ツールはスクロール位置を個別に記憶し、タブを切り替えても失われません。すべての結果はワンクリックでコピーでき、操作には必ず Toast フィードバックがあります。

テーマシステム

月ごとに追従する 12 種類の配色テーマを内蔵し、既定で現在月に自動切替します（1 月は冬のヒイラギ、4 月は桜色、8 月は秋の金色……）。特定月のテーマを手動指定することも、設定パネルのカラーピッカーで 5 色テーマ（背景色・主色・強調色・文字色・補助色）を自作することもできます。5 つの基本色から CSS 変数の一式を自動導出し、全グローバルへリアルタイム適用。定番のライト / ダーク外観も内蔵しています。

踏んだ落とし穴

開発では Tauri と WebKitGTK の難問をかなり解決しました：一部のコーデックライブラリは Web 環境での挙動が一致せず、Rust 側でパラメータ調整が必要；WebKitGTK は一部の PNG/GIF の描画で色の差が生じるため、画像変換の結果を一つずつ比較検証；内蔵 ffmpeg の最小化コンパイルは依存を何度も削ぎ落として、機能の完全性とインストーラー容量の両立を図りました。この経験は再利用可能な「ファイルダイアログ + 内蔵バイナリ + タスク進捗」の基盤として蓄積され、以後の新ツールは設定 1 行を登録するだけで接続できます。

クロスプラットフォームとパッケージング

プロジェクトは GitHub Actions で Linux（deb / rpm / AppImage）・Windows（NSIS、クロスコンパイル可）・macOS の複数プラットフォーム向けインストーラーを構築します。フロントは Vite でビルドし、Rust バックエンドは各プラットフォームのネイティブバイナリへコンパイル。アプリ全体は小さく起動が速く、VineTurtle Studio のオープンソースプロジェクトとして Linux と Windows の両方で検証済みです。

おわりに

VinePalma Toolbox は現在 0.2.0 で、40 本あまりのツールを収録し、すべてローカル処理・ネット依存なしです。「デスクトップツールボックスだって、軽さと網羅性を両立できる」ことを証明したい：1 個の Tauri アプリで、点在する Web ツールの山と重い単機能ソフトを置き換えます。今後はツール種別の拡充と高解像度ディスプレイ対応の精緻化を予定しています。GitHub でのご提案を歓迎します。一緒にさらに良いものにしましょう。
